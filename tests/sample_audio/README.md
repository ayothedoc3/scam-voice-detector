# Sample Audio Files

This directory should contain test audio files for development and testing.

## Sources for Sample Audio

1. **Synthetic/AI-Generated Voices:**
   - ElevenLabs samples
   - Resemble AI demos
   - Voice.ai examples

2. **Authentic Voices:**
   - Common Voice dataset
   - LibriVox recordings
   - Personal recordings (with permission)

3. **Scam Audio:**
   - YouTube scam call recordings
   - r/Scams audio clips
   - FTC scam examples

## File Naming Convention
- `scam_[description].mp3` - Known scam/AI-generated
- `authentic_[description].mp3` - Real human voice
- `test_[description].mp3` - General test cases

## Notes
- Keep files under 10MB for quick testing
- Include variety of accents, ages, genders
- Add metadata file describing each sample
