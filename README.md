# 🔊 Voice Scam Detector

AI-powered deepfake voice detection to protect against phone scams.

## Quick Start

**Backend:**
```bash
cd backend
pip install -r requirements.txt
cp .env.example .env  # Add your Resemble API key
uvicorn main:app --reload
```

**Frontend:**
```bash
cd frontend
streamlit run app.py
```
